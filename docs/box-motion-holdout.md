# Движение с замороженным Fast

Отдельно проверяем качество движения, не переобучая детектор #42 и не меняя ни одну текущую рамку. Частая ошибка прошлого пилота — предсказать движение для стоящего объекта; другая крайность — не сместить ни одного движущегося.

Для одного якоря доступны четыре наблюдённых шестикамерных снимка. На последних трёх получаем по набору боксов (модели на каждом снимке нужен предыдущий). Переводим исторические центры через их ego-позы в систему текущей машины. Если на обоих соседних интервалах есть однозначные взаимные соответствия и направления/скорости не противоречат друг другу, оцениваем скорость. При слабой опоре возвращаем ровно ноль и код причины. ID клетки — не ID объекта. Коррекция меняет только `velocity_xy`; штатный агент не переключаем.

## Данные и ослепление

Фиксируем две другие поездки OpenScene Mini и подбираем окна по наличию движущихся аннотированных автомобилей, **до вывода модели**. Это целевая выборка движения, не случайный срез трафика и не оценка CARLA. Используем те же шесть ракурсов nuPlan, что и в первом этапе. Часы каждого JPEG неизвестны: время в OpenScene — ассоциация с LiDAR, не доказательство синхронных экспозиций. Модель была обучена на nuScenes; перенос между наборами может быть слабым.

Подготовка сверяет закреплённый OpenScene архив и разносит входы и метки. `predict` монтирует только каталог inputs, замороженные веса Mini и DINOv2; сохраняем SHA256 файла до подключения разметки. Два инференса повторяем без целей. `score` требует тот SHA256 и читает только сохранённые результаты и отдельные targets. Предсказанные режимы и пороги не выбираем по финальному набору.

## Что считаем

- Одно сопоставление текущих центров (greedy XY ≤2 м) для всех трёх режимов: неподвижный бокс, исходная голова #42, ассоциация истории.
- На совпавших объектах с продолжением считаем отдельно **чистую ошибку смещения** и **ошибку будущего центра**. Движением считаем истинное смещение ≥0,50 м до следующего кадра; неподдержанные и несовпавшие объекты не исчезают из счётчиков.
- Условие успеха пилота: ≥12 совпадений движущихся целей (объект×кадр) в двух поездках, выигрываем ≥0,10 м по смещению у подвижных, ухудшаем ≤0,05 м у тихих и не ухудшаем общую ошибку следующего центра. Если не хватает совпадений или точности, не меняем штатный режим. Это целевой порог эксперимента, не критерий безопасности.
- Опционально сравниваем порядок продольных вариантов для разных скоростей боксов. Это диагностика соединения, не измерение предотвращённых столкновений.

Запуск в закреплённом `Dockerfile.alignment` с отключённой сетью: `scripts.prepare_box_motion_holdout` → `scripts.run_box_motion_holdout predict` → фиксация SHA256 → `scripts.run_box_motion_holdout score --sealed-sha256 …`. Источник данных: [OpenScene Mini](https://github.com/OpenDriveLab/OpenScene/blob/main/docs/getting_started.md).
